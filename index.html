🗄️ Cloudflare D1 Database Connection Guide

Persistent Storage

সকল কাস্টমার চ্যাট, মেসেজ হিস্ট্রি এবং বট কনফিগারেশন স্থায়ীভাবে Cloudflare D1-এ জমা থাকবে।

Cloudflare Dashboard-এ D1 বাইন্ড করার সহজ ধাপ:
  1. Cloudflare Dashboard-এ লগইন করে বাম মেনু থেকে Workers & Pages এ যান।
  2. আপনার Worker (social-automate) সিলেক্ট করুন।
  3. উপরের Settings ট্যাবে ক্লিক করে বামে Bindings সিলেক্ট করুন।
  4. Add binding বোতাম চেপে D1 Database সিলেক্ট করুন।
  5. Variable name দিন: DB (অবশ্যই বড় হাতের DB হতে হবে)।
  6. D1 Database ড্রপডাউন থেকে আপনার ডেটাবেস সিলেক্ট করুন (যদি তৈরি না থাকে, তবে বামে D1 SQL Database মেনু থেকে 1 ক্লিকে তৈরি করে নিন)।
  7. Save and Deploy চাপুন। ব্যাস, সম্পূর্ণ D1 সক্রিয় হয়ে যাবে!
