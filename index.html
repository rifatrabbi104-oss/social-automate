🗄️ Cloudflare D1 Connection Guide

Business DB
Cloudflare Dashboard-এ D1 বাইন্ড করার সহজ নিয়ম:
  1. Cloudflare Dashboard > Workers & Pages এ যান।
  2. আপনার Worker (social-automate) সিলেক্ট করুন।
  3. Settings > Bindings > Add binding-এ ক্লিক করে D1 Database বেছে নিন।
  4. Variable name: লিখুন DB (বড় হাতের DB)।
  5. D1 Database: আপনার D1 ডেটাবেস সিলেক্ট করে Save and Deploy চাপুন।
